Prompt Injection Test Kit — FAQ

Everything you need before you run your first attack.

What is the Prompt Injection Test Kit?

A ready-to-run battery of graded prompt-injection cases that tells a defended AI agent from an undefended one. You attack your own agent before an attacker does.

Do I need to buy it to try it?

No. A free 10-case sampler with two bundled mock agents is on the product page. The full kit is a one-time $49.

What languages / frameworks does it support?

Any. The runner talks to your system through a one-function adapter, so it is agnostic to model provider, framework, and language.

Does it run in CI?

Yes. The runner exits non-zero on any obeyed injection, so you can gate a deploy on it exactly like a test suite.

Who makes it?

King AI. See the quick-start guide to run your first battery in under a minute.
