Prompt Injection Test Kit — Quick-start Guide

Run the kit against your own AI agent in under a minute.

1. Get the sampler

Download the free 10-case sampler from the Prompt Injection Test Kit product page. It contains ten graded injection attempts and two bundled mock agents — one defended, one not.

2. Score the mock agents

python3 run_kit.py --agent mock_defended
python3 run_kit.py --agent mock_undefended

The harness prints a pass/fail per case and a final score. A defended agent refuses the injected instruction and reports it as a finding; an undefended one obeys it.

3. Point it at your agent

Implement the thin agent(prompt) -> response adapter shown in the README, then re-run. The same ten cases now grade your real system, so you see exactly which injection shapes get through before you ship.

What the full kit adds

  • 120+ graded cases across path-redirect, value-correction and authority-spoof families.
  • A CI-ready runner that exits non-zero on any obeyed injection.
  • Regression tracking so a fix that closes one case never silently reopens another.
